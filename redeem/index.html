Redeem a code

Got a Boombaland code from our socials? Enter it here, then open the game and tap Collect.

You need to be signed in in the game (Settings › Account › Cloud save across devices). Your player ID is under Settings › Account › Player ID; tap Copy and paste it below. Each code works once per save.

Codes are free and are never sold. A reward arrives in the save you choose, the next time you open that save while signed in.
